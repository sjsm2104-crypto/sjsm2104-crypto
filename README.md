## Proyectos

### [EcoRoute Logistics](https://github.com/EcoRoute-Logistics/EcoRoute-Logistics)
SaaS para optimizar las rutas de entrega de flotas pequeñas en Barranquilla. Hice el frontend: landing, inicio de sesión, rutas protegidas por rol, panel de entregas, mapa de rutas con Leaflet trazado por las calles con OSRM, portal del conductor para celular y modo oscuro.

### PyAdapta *(en desarrollo)*
Tutor de Python adaptativo para colegios que funciona sin internet. Genera apuntes con un modelo de IA local, verifica el código de los ejemplos y ejercicios dentro del navegador, y ajusta la dificultad con un quiz que sube o baja de nivel según las respuestas del estudiante. Es mi proyecto de tesis y está en desarrollo: la base técnica está terminada y faltan la revisión de los apuntes, la prueba en celular y un piloto con estudiantes.

- Quiz adaptativo con 252 preguntas, prueba de nivel y plan de estudio.
- Verificador de código con 28 correcciones automáticas sin IA, que corre Python en el navegador con Pyodide.
- Apuntes generados con Ollama (`qwen2.5-coder:3b`) en una cola con cancelación.
- Exportación anónima de resultados con HMAC-SHA256, y respaldo y restauración de la base de datos.
- Más de mil pruebas automáticas.

Stack: Flask, SQLAlchemy, SQLite, Waitress y JWT en el backend; React y Vite en el frontend.
